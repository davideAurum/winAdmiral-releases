# winAdmiral releases

Downloads for **winAdmiral**, a native file manager for Windows by David Goldblatt. This repository holds release
files only; the source code is not published here.

No public release is available yet. When one is, it will appear under
[Releases](https://github.com/davideAurum/winAdmiral-releases/releases), with:

- `winAdmiral-<version>-setup.exe`: an installer, for your account only or for all users of the PC.
- `winAdmiral-<version>-win-x64-self-contained.zip`: a portable copy that needs nothing else installed.
- `winAdmiral-<version>-win-x64-framework-dependent.zip`: a smaller portable copy that needs the .NET 10 Desktop Runtime.
- `SHA256SUMS.txt`: checksums to verify the downloads.

Each download carries its license in `LICENSE.txt`. The builds are not code-signed yet, so Windows SmartScreen may warn
the first time you run one.
